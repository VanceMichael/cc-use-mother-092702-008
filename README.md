# 广告流量结算与责任扣留

在责任审核、投放结算和追偿之间保持广告资金账与扣留状态一致。

## 参与方与事实

主要参与方包括广告主财务人员、平台结算人员、渠道商、法务与风控人员。领域资料记录以下事实：

- 数字人广告可以低成本批量生产并快速购买流量
- 广告主、发布者、制作机构和销售方都可能承担责任
- 违规内容下架后仍需处理已发生的投放和分成

## 业务边界

- 审批状态
- 流量回执
- 分成比例
- 风险扣留
- 追偿冲正

当前资料按以下边界组织：

- 投放订单
- 流量回执
- 佣金账本
- 风险冻结
- 关账追偿

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/settlement_context.py` 负责读取和校验资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

命令只读取仓库内文件，不需要连接外部业务系统。
